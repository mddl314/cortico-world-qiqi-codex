# 鳍鳍的 Codex

作者：末地凋零

将本机 Codex CLI 接入 Cortico。Bot 可提交任务和文件权限申请，操作者可在 World 面板审核、查看运行记录或停止任务。

## 安装与初始化

需要 Cortico World API 6、Node.js 22 或更新版本、支持命名权限的 Codex CLI（验证版本 0.171.0）。先在 Cortico 主机运行 `codex login`。Windows 需要能运行 Codex 的 MXC 或 elevated 沙箱；其他平台需提供该平台支持的 Codex 沙箱。

1. 在 Cortico 扩展管理中按包名安装 `cortico-world-qiqi-codex`。手动安装时，也可以选择包含 `package.json` 的本地源码目录。
2. 在已安装的扩展目录运行 `node setup.mjs "<包含 config.json 的 Bot 部署目录>"`，记下一次性初始化码。
3. 重启 Cortico 并启用此 World。在「我的 World → 鳍鳍的 Codex」输入初始化码并设置自己的访问码。

原访问码和历史可以继续使用。在「设置」可更改访问码，旧会话随之失效。插件访问码默认开启，可直接关闭。关闭时，能访问 Cortico 面板的人可查看任务和更改设置。

## 面板

- 「任务」查看当前任务、待审核申请、实时记录和历史，运行中可停止 Codex。「设置」调整权限、等待时间和访问码。
- 发送前审核默认开启。鳍鳍主动提交后，「任务」显示待审核任务和实际发送的全文。点「批准并发送」才提交给 Codex，也可以拒绝。
- 关闭审核后，新任务会直接发送。已待审的任务仍需手动处理。
- 运行中可点「停止 Codex」，取消本机调用。已经发给服务的内容无法撤回。
- 实时运行记录显示 CLI 已发出的阶段、命令及截取的输出、文件变更和消息。任务完成后可在历史中回看最近 60 条事件。
- 工作文件夹可设为「只读」或「目录内读写」。需要读工作区外的文本时，在「额外只读路径」贴入该文件或文件夹的绝对路径。开启基础权限代选后，鳍鳍能按任务选用主人预授权的目录和模式。
- 鳍鳍可以填写任务、目录、模式和理由来申请一次性权限。默认由主人决定。开启「允许鳍鳍同意或拒绝权限申请」后，鳍鳍只能同意没有超出主人现有目录与权限的申请。任务发送审核仍单独生效。
- 运行上限默认为 10 分钟，可在面板设为 60 秒到 1 小时。等待人工批准的时间不计入。变更适用于下一次开始运行的任务。
- 最近 50 条任务保存在本机，最多一条处于待审或运行状态。历史条目展开后可查看实际请求和最终答复。旧版的历史仍在 Cortico 控制台工具卡内。

鳍鳍用 `qiqi_codex_ask` 提交任务。任务在后台执行，结束后 Cortico 给鳍鳍发出状态事件，鳍鳍可用 `qiqi_codex_result` 查结果。

给鳍鳍的验收话术：

> 请用你的 Codex 工具读取实验工作区的「验收样例.txt」，告诉我文件里的实验代号。

新安装的默认目录是 Bot 部署目录下的 `workspace/qiqi-codex`。已批准或跳过发送审核的任务会发给 Codex 服务。运行记录和访问码校验值保存在 Bot 的本地 `worlds/qiqi-codex` 下。

Codex 可以读取已授权范围内的文件，文件内容可能随任务发送至 Codex 服务。授予目录内读写时，Codex 可以在目录内创建、修改或删除文件。运行记录可能包含任务文本和命令输出，供拥有面板访问权的人查看。

扩展可在 Cortico 扩展页停用。重新安装或替换代码后需要重启 Cortico。
